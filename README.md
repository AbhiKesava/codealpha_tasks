# Basic Network Sniffer

A simple Python-based network sniffer built using Scapy.

## Features

- Captures live network packets
- Displays:
  - Source IP
  - Destination IP
  - Protocol information
  - Payload data
- Supports:
  - TCP
  - UDP
  - ICMP

## Technologies Used

- Python
- Scapy
